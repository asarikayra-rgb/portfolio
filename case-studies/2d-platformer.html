The Problem / Goal

Create an engaging 2D platforming experience with responsive character controls, enjoyable jumping mechanics, and handcrafted levels that encourage exploration.

The goal was to build a playable platformer with multiple levels, collectible objects, clear progression, and a satisfying level completion objective.

My Role: Game Design, Level Design, Gameplay Development, Character Animation, Tilemap Design, and Collectible Systems.

Key Features

Responsive Movement Character movement and jumping tuned for smooth platforming and better player control.
Handcrafted Levels Two selectable levels with different platform layouts and jumping challenges.
Collectibles Collectible objects encourage exploration and reward players during gameplay.
Character Animation Character animations provide visual feedback during movement and gameplay.
Platform Challenges Floating platforms at different heights create jumping and navigation challenges.
Level Completion A trophy provides a clear objective and visual indication of level completion.
Level Selection A main menu with separate Level 1 and Level 2 selection.
Pixel Art Style A 2D pixel-art visual style creates a consistent platforming environment.

Design Highlights

  • Designed platform layouts with different heights to create varied jumping challenges.
  • Used collectibles to encourage optional exploration.
  • Focused on responsive movement and jumping to make platforming feel enjoyable.
  • Introduced multiple levels to provide structured gameplay progression.
  • Used a trophy as a clear visual goal for level completion.
  • Designed a simple menu and level-selection flow to make navigation easy.

Playtest & Iteration

During development, I worked on gameplay responsiveness, project debugging, and level structure to improve the overall platforming experience.

  • Movement Tuning: Worked on jump and acceleration settings to improve character control and platform navigation.
  • Debugging Issues: Encountered script errors that initially prevented the project from launching correctly in Debug mode. Investigated script and project setup issues.
  • Level Design: Worked with platform placement and different heights to create more engaging jumping challenges.
  • Godot Workflow: Explored Godot 4's scene, node, and TileMap workflows while developing the game environment.
